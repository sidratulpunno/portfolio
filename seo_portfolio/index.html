02

Quantum ML for Network Security

  • Evaluated parameterized quantum kernels for one-class intrusion detection on CICIoT2023 and UNSW-NB15; PSO-tuned RFF surrogate validated against exact fidelity kernel.
  • No detection advantage over classical RBF one-class SVM, with surrogate-to-exact fidelity analysis.

IoT Security | Anomaly Detection | Swarm

03

Quantum-Inspired Decentralized IoT Anomaly Detection

  • Decentralized framework combining benign-reference fidelity-density detector with swarm-inspired peer corroboration.
  • CICIoT2023 / X-IIoTID ROC-AUC 0.9706 / 0.8758; 50-node NS-3 (3-of-3 delivery, 10.8424 ms latency).
